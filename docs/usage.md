# 鸢笺 · Yuanjian 使用说明

## 文件与保存

先用顶部文件夹按钮打开 Markdown 或 `.txt` 文件即可书写。“添加目录”是可选的整理入口，可添加多个位置；移除入口不会删除文件。

已命名文件默认自动保存。未命名内容作为草稿留在会话中，`Ctrl+S` 选择实际保存位置。关闭软件会保存已命名文件与草稿；写入失败或发生冲突时窗口保留并显示原因。

完整窗口启动时在鼠标所在屏幕居中；成功打开新文件时，在窗口当前屏幕居中，保留大小和最大化状态。切换已经打开的标签、输入和后台刷新不移动窗口。便笺另记自己的位置。

顶部标签可左右拖动排序，图谱也参与排序；拖到边缘会滚动标签栏，松手才确认，Esc 或拖出栏外取消。拖动未激活标签不会切换当前正文。标题栏在标签滚动区外保留空白，便于抓住并移动窗口。

`Ctrl+P` 按文件名或路径快速查找已打开笔记和已添加目录中的笔记；上下键选择、Enter 打开、Esc 返回正文。`Ctrl+O` 仍打开系统文件选择框。

标签右键菜单可关闭当前、其他或右侧标签，复制路径、定位文件；批量关闭遇到取消、冲突或保存失败即停止后续操作。`Ctrl+Shift+T` 重开最近关闭的已命名笔记；明确丢弃的未命名草稿不自动恢复。重开从磁盘读取并开始新的撤销记录；仍打开的笔记在标签/图谱间切换时保留各自撤销。

外部编辑器修改了文件，未修改的标签自动刷新；双方都改动时尝试三方合并。无法合并时可比较两份原文，选择保留双方或明确保存本地版本。外部删除文件不会自动把它重新创建。

图片粘贴/拖入前需保存笔记，附件放在邻近 `assets`，保存相对路径。网络图片保留网址；笔记操作菜单的“网络图片本地化”可选择单张或整篇下载，失败会保留原链接。

## 编辑与链接

即时排版中，光标进入当前格式时显示需要编辑的标记，列表和引用保留周围排版；阅读时不为标记预留空白。拖选期间保持排版，松手后展开选区。完整源码模式可检查所有 Markdown。代码只用于记录，不执行。

空列表项或空引用行按 Enter 退出当前一级；独占一行的三个反引号（可带语言）或 `$$` 后按 Enter 可补齐结束标记。方向键可进入代码、公式及表格，保留 Tab 切格等操作。

格式面板的“插入 Markdown 语法”提供提示块、高亮、上下标、注释、目录、嵌入和脚注模板，插入后直接填写，支持撤销。高亮写作 `==重点==`，上下标写作 `x^2^`、`H~2~O`。这些标记不会作用于代码或 LaTeX 公式内部。

提示块使用 `> [!info]`、`> [!NOTE]` 等写法，支持自定义标题、嵌套，以及 `+` 默认展开、`-` 默认折叠。独占一行的 `[TOC]` 或 `[toc]` 根据当前标题生成目录。有限 HTML 支持 `<br>`、`<u>`、`<sup>`、`<sub>`、`<mark>`、`<details>/<summary>`；不执行脚本或任意网页样式。

`%%注释%%` 和 `<!--注释-->` 在阅读及 HTML/PDF 中隐藏，源码和 Markdown 导出保留原文。隐藏注释中引用的附件仍受清理保护。

`![[图片.png|240]]` 可指定图片宽度；`![[笔记]]`、`![[笔记#标题]]` 可嵌入只读笔记内容。段末 `^definition` 定义块标识，`[[笔记#^definition]]` 跳转、`![[笔记#^definition]]` 嵌入该段。嵌入使用已打开笔记的当前编辑内容；未打开的笔记须在已添加目录或既有文件授权范围内，自动预览不会扩大授权。缺失、重名、重复块标识、循环引用或过大内容会提示原因，可打开原笔记处理。嵌入最多 12 层、128 次、约 2 MiB 内容。

HTML 导出保留提示块和详情区的折叠状态，PDF 展开全部内容；两者将嵌入笔记固定为导出时的内容。无法解析的嵌入会阻止导出并提示，Markdown 导出继续保留引用写法。

跨段落的粗体/斜体分别处理正文内容，不把空行、标题或列表前缀套进同一对星号；重复点击取消。`[^注]` 与 `[^注]: 注释内容` 提供脚注，Ctrl+单击跳转，阅读位置后退可返回；复制渲染脚注时携带引用与定义。

`Ctrl+Shift+F` 打开跨文件搜索，空格分词表示全部包含，双引号表示短语。搜索包含已打开标签当前内容和未保存草稿；选定目录时只查该目录中的文件。结果按笔记分组，命中摘要可展开，不可读取的位置另列。目录可用方向键、Home/End、Enter 操作，折叠状态会保存；“定位当前笔记”展开相应路径。F6/Shift+F6 在可见导航、正文和大纲间切换焦点。

设置中录制冲突快捷键时先保留原绑定；可分配动作可点击“替换原绑定”，固定编辑操作不能抢占。未完成或无效的录制不会直接写入有效设置，旧配置不会被静默重置。

输入光标亮、灭各约 0.53 秒，开启系统“减少动画”时也保持此节奏。此版本使用固定周期，不会动态读取后续的 Windows 光标速度设置。

表格单元格可以直接编辑，Shift+Enter 格内换行，Tab / Shift+Tab 前后切换；最后一格按 Tab 新增一行，Enter 结束格内编辑，Esc 撤回这次格内修改。输入立即进入正文；表格工具可添加/删除行列和调整对齐。多格粘贴后可用 Ctrl+Z 撤销。代码块可设语言、复制、折叠，行号和换行在设置中控制。

## 复制、粘贴与导入

从网页或 AI 对话复制的整段回答，普通粘贴转换为 Markdown，保留表格、文字、代码和公式。代码块或公式源码中的普通粘贴保留纯文字，Ctrl+Shift+V 始终粘贴纯文字。来源没有表头的表格会补空表头，第一行仍是数据；合并单元格会展开并提示，原文字保留。

往单元格粘贴明确的 HTML 表格或 TSV 数据，会从当前格开始填入并按需扩展，覆盖非空内容前需确认。普通多段文字保留在当前格内。表格工具和右键提供“复制整表”；普通选区也同时携带 Markdown 和干净的 HTML，不带编辑按钮。完整公式携带 LaTeX，只选公式的一部分则复制选中的可见文字；无法安全对应源码时禁止剪切。

富文本复制会尝试携带本地图片数据，粘到另一篇已保存笔记后走该笔记的附件流程；外链图片保留网址，不自动下载。本地图片单张最多携带 8 MiB、一次合计 24 MiB；无法携带的格式或超限图片保留说明并提示，其他文字照常复制。纯文本粘贴不会自动修正图片路径。

应用菜单与便笺“更多”中的“导入文件”支持 Markdown、TXT、HTML、CSV/TSV 和图片。Markdown/TXT 打开原文件，之后按正常笔记规则编辑和保存；HTML 转为未保存草稿；CSV/TSV 先确认编码、分隔符和首行是否表头，再生成草稿，取消不修改当前笔记。转换不会覆盖 HTML/CSV/TSV 原文件。Word、PDF、Excel 工作簿的完整转换尚不支持。

拖入笔记文件会打开标签，图片拖到正文才插入目标笔记，文件夹作为左侧目录添加。多个文件逐项反馈，不支持的文件不插入正文。网页文字和表格拖入复用粘贴转换；笔记内部拖动选区保留移动/复制操作。

导入 HTML 的相对图片与链接按来源目录解释。首次保存会复制可确认的本地图片、调整引用并保留源文件；来源目录以外、缺失或无法确认的资源保留引用并提示，远程图片不自动下载。导入来源在外部改变时需要重新导入，当前草稿保留。

标题按钮提供正文与 H1–H6，并标出当前级别。选中多行时，标题、列表和引用作用于所选各行；粗体、斜体、列表和引用再次应用可取消，混合格式选区统一应用目标格式，操作支持撤销。

`Ctrl+F` 打开中文查找栏，显示命中数和前后项；`Ctrl+H` 或“展开替换”显示替换输入。大小写、整词和正则在“选项”中调整，Esc 关闭查找并回到正文。设置搜索与正文查找是独立入口。

行内公式用 `$...$`，独立公式用 `$$`。在公式中输入 `frac`、`sum` 等，从补全选片段，Tab 跳转参数。片段可在设置中修改。支持 KaTeX 的 LaTeX 命令；语法错误显示在当前公式附近。

Mermaid 代码块支持流程图、时序图等，图表仍保存为普通 Markdown 文本。

标准相对链接和 `[[双链]]` 可导航，支持标题锚点；重名目标会提示。单文件模式可跟随磁盘正文中已保存的具体 Markdown 链接；新写但尚未保存的链接先保存再打开。

即时排版中普通单击链接用于编辑，Ctrl+单击打开；光标在链接中时也可按 Ctrl+Enter 打开。独立阅读预览仍可单击打开。未保存草稿中的 HTTPS 网址可以直接打开，相对文件链接仍需确定笔记位置。链接、大纲和搜索跳转后，可用 Alt+← / Alt+→ 返回或前进到之前的阅读位置。

工具栏“链接”打开选择面板。选择笔记后默认填入相对当前文件的路径，可修改显示文字或手填网址、标题锚点；插入支持撤销，取消不改正文。

## 外观与字体

“设置 → 字体管理”可分别选择界面、正文、标题和代码字体。每个选择面板支持搜索、按来源分组及字形预览；当前字体置前，同名字体合并并标明来源。上下方向键选择，Enter 应用，Esc 取消，搜索和浏览不会自动修改字体。

下方管理列表分为内置、已下载/已导入、系统三组，系统字体默认收起；搜索始终覆盖全部来源，清空后恢复原分组状态。展开的列表限定高度，可在内部滚动。已下载/导入的同名文件仍分开管理，可分别移除。

内置 Noto Sans SC、Noto Serif SC、Inter、JetBrains Mono；额外字体可下载或导入字体文件/ZIP。下载/导入的字体留在软件数据目录，不安装到 Windows 字体目录。系统字体只读取可用名称，列表中看见它们不代表软件额外复制了一份字体包。

“外观与主题”可选择静态壁纸，调整填充、位置、亮度、模糊和透明度；正文与侧栏底色透明度分别控制。内置中性灰、中性墨灰、苔绿、暖铜与纸色、雾蓝石板、麦纸琥珀、雾玫瑰和鸢紫八套配色，均有明暗两版。切换配色保留字体与壁纸；自定义颜色分别保存在当前明暗版本。颜色主题和包含字体、壁纸的完整外观方案分别管理。外观修改先预览，点击“应用外观”后保存，取消恢复原设置。代码字号和行距在“编辑与文件”单独调整。

界面区块、工具栏按钮和快捷键均可配置。侧栏可拖动调整宽度或收起。

## 便笺模式

点击右上角“进入便笺模式”，当前窗口变成小便笺，沿用当前笔记、字体、主题和壁纸；正文仍能编辑，保存规则不变。按住标题栏左侧点状把手移动整个窗口，拖边调整大小；标题文字用于切换笔记，正文用于编辑和选字。图钉按钮开启或取消始终置顶。首次默认置顶，之后记住选择。

点击标题可换到其他已打开笔记；“更多”保留打开、新建及常用编辑。设置、历史、图谱和导出等操作会先返回完整界面。右上角“返回完整窗口”恢复原窗口和布局，便笺最大化时也返回完整界面。

关闭便笺仍会保存并退出，保存失败或冲突会保留现场；最小化进入任务栏。每次重新启动、从资源管理器打开文件都进入完整界面。便笺尺寸、位置和置顶选择会另行记住，不覆盖完整窗口的位置。

## 日记与图谱

在“日记与周期”选择目录、命名规则和周/月记开关，在“模板与片段”修改对应模板。支持 `{{title}}`、`{{date}}`、`{{year}}`、`{{month}}`、`{{week}}`。

日历的“打开 / 新建日记”定位该天的主要日记；“按模板另写一篇”创建 `日期-2.md`、`日期-3.md` 等，保留已有文件。多模板时先选择模板。

顶部“关系图谱”打开全局图，右侧“查看局部关系图”打开当前笔记的一层关系。可调整层数、标签/附件开关、目录和标签筛选；拖动、缩放或搜索节点，点击笔记打开。布局和视口会记住，可重置。

图谱在首次打开时加载本地组件，不需要联网下载。加载失败可重试或返回笔记，编辑内容保留。

## 历史、附件与导出

正文已经写入而历史备份失败时，会说明“正文已保存，历史备份未完成”，可单独重试历史；未完成的保存/移动历史也会在下次启动提示，并列在版本历史面板。重试不会再保存、移动或覆盖正文。若图片当时无法读取，或补记清单也无法落盘，会说明无法保证退出后的原图备份，不把当前图片冒充原版本。

笔记操作菜单可查看版本历史，比较、固定或恢复。默认保留 30 天、500 MB，可在设置中修改。存在的笔记会保护最近一份和固定版本；已删除笔记到期后包含最后一份一起清理，容量不足时可能提前清理。历史清理不删除原笔记或原附件。

删除笔记会移入系统回收站，附件仍保留。“检查未引用附件”只检查已添加目录及已批准笔记/草稿的引用，列表是疑似闲置项。核对路径后手动勾选，确认才移入回收站；不会自动清空。

读取或解析无法确定引用的附件会标明原因并禁用勾选；清理前重新核验，重新扫描会移除已经不再符合条件的勾选。移动文件后如果只剩历史更新失败，界面准确显示已移动的位置，分别提供撤销移动和重试历史更新；历史重试不会再次搬动文件。

阅读预览可导出 PDF 或 HTML，默认白底、不含壁纸；可选择主题和壁纸。PDF 等待字体和图片加载完成，缺失图片或错误图表会报错。HTML 内嵌本地图片和选用的内置/导入字体，远程图片保留网址；系统字体由接收电脑提供或回退。需要一致的离线 HTML 时先本地化图片，并选择内置/导入字体。

Markdown 与附件 ZIP 会复制实际引用的本地图，并只在导出副本中整理路径；原文件不修改。

## 更新与备份

退出旧版本后，在同一安装位置运行新安装包。程序和用户数据分离，设置、字体、会话、历史不放在安装目录。可从设置打开数据目录备份；笔记与源附件保存在你自己选择的目录，也应一并备份。

软件名称为“鸢笺 / Yuanjian”，可执行文件为 `Yuanjian.exe`。默认数据目录为 `%APPDATA%/鸢笺`；首次升级会复制并校验旧版 `%APPDATA%/轻笺` 中的设置、字体、历史与草稿，成功后才切换，旧目录留作备份。新目录已有数据时直接使用它，不合并或覆盖。迁移失败会保留原数据并继续使用旧目录，同时显示原因。安装器保留原升级 GUID，内部应用标识改为 `local.yuanjian.notes`。

当前 Windows 安装包尚未签名，暂不支持自动更新。
